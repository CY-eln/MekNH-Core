> ## ⚠️ 重要说明
>
> **本模组专为 Mekanism：New Horizon 整合包设计，不保证独立安装与其他整合包的兼容性。**
>
> - 机器、化学品、配方与平衡数值都是围绕该整合包的整体进度设计的，单独安装时可能出现配方缺失、进度断层或数值失衡。
> - 模组会读取并接管部分 Mekanism 行为（Mixin、JEI 分类、数据驱动注册），与其它修改同类内容的模组冲突时不做兼容处理。
> - 只有在该整合包环境中才会进行测试与问题修复；其它环境的崩溃、配方冲突、世界生成异常不在支持范围内。
> - 如需在自己的整合包中使用，请自行验证并承担相应风险。

MekNH Core 是 Mekanism：New Horizon 整合包的核心模组。

## 多方块结构预览

- 在 JEI 的「多方块结构」分类查看结构，并打开可旋转、缩放、逐层查看的 3D 预览。
- 主方块只查询自身结构；材料按 U 查询相关结构，通过 JEI 原生配方翻页切换。
- 预览显示所需材料和选中位置的候选方块；点击材料或候选图标查看其合成来源。
- 材料用量是代表性统计，不代表可替换部件的唯一搭法。

客户端需要 **LDLib2 2.2.46.a**（`[2.2.46.a,2.2.47)`），配合 JEI 使用；服务端不强制安装 LDLib2。

开发回归：先用 JDK 21 执行 `./gradlew build` 准备依赖缓存，再运行 `bash devtools/check-structure-preview-v1.sh`（离线）。可用 `JAVA_HOME`、`GRADLE_USER_HOME` 指定环境，`RUN_STRUCTURE_GPU=1` 启用可选 GPU 检查。此检查覆盖状态、网格、视口、拾取及构建产物契约；不替代整合包内的交互验收。
